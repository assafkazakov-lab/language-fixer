Language Fixer Hebrew ↔ English keyboard converter

How to use

  1. 1 Type in any text field. If wrong-language text is detected, a suggestion chip appears near the field.
  2. 2 Click the chip to convert the text and save a language preference for this site. A reminder will nudge you to switch your keyboard.
  3. 3 Press ⌥⇧F to trigger the same action from the keyboard without clicking.

Keyboard shortcut

Fix language ⌥ Alt⇧ ShiftF

OS keyboard switch shortcut

After converting text the chip shows this shortcut as a reminder. When you press it, the chip auto-dismisses.

Site preference

Saved for this site: none

This extension only converts typed text using a keyboard layout map. It does not change your OS or system keyboard language.
